# 🎂 토핑케이크 롤링페이퍼

도트 케이크 위에 메시지를 토핑처럼 올리는 온라인 롤링페이퍼예요.

- 받는 사람을 정해 케이크를 굽고, 링크를 보내면 누구나 **로그인 없이** 메시지를 올릴 수 있어요.
- 딸기·체리·초·마카롱 등 12가지 토핑과 5가지 쪽지 색을 고를 수 있어요.
- 완성된 롤링페이퍼는 **B4 크기로 바로 출력**하거나 **B4 PDF**, **PNG 이미지**로 저장할 수 있어요.

## 토핑케이크 사진첩

첫 화면에서 **② 토핑케이크 사진첩**을 고르면 사진첩을 만들 수 있어요.

- **새 사진첩 만들기** → 링크가 나와요. 링크를 받은 사람도 사진을 보탤 수 있어요.
- 사진은 **사진첩을 만든 사람의 구글 드라이브** `토핑케이크 사진첩 (사진 저장소)` 폴더에 저장돼요. 링크로 언제든 다시 열어 고치고 인쇄할 수 있어요.
- 사진에 저장된 **찍은 시간(EXIF)** 순으로 자동 정렬해요. 날짜는 직접 고칠 수 있어요.
- 사진을 **자르지 않고 원본 비율 그대로**, 사진 모양에 맞춰 한 쪽에 2~4장씩 배치해요.
- 사진마다 **⤢ 크게** 버튼을 누르면 그 사진이 한 쪽을 혼자 크게 차지해요.
- 권한: 제목·꾸밈·순서는 만든 사람만, 사진의 날짜·설명·빼기는 올린 사람과 만든 사람만 바꿀 수 있어요.
- 저장하지 않고 기기 안에서만 만들기도 가능해요.

### 학교 프린터로 소책자 인쇄

**📖 소책자로 인쇄하기**를 누르고 인쇄 창에서:

1. 용지 **B4**, 방향 **가로**, 배율 **실제 크기(100%)**, 여백 **없음**
2. **양면 인쇄 → 짧은 쪽으로 넘기기**
3. 나온 종이를 순서대로 겹쳐 **반으로 접고 가운데를 스테이플러로** 찍으면 완성

쪽 수는 자동으로 4의 배수로 맞추고(남는 쪽은 빈 쪽, 맨 끝은 뒤표지), 접었을 때 순서가 맞게 배열돼요.
양면 인쇄가 안 되면 **소책자 PDF**로 저장해 홀수 장 → 종이 뒤집어 짝수 장 순서로 인쇄하세요.

### 사진첩용 Apps Script 업데이트 (처음 한 번)

1. Apps Script 편집기에 최신 `apps-script/Code.gs`를 붙여 넣고 저장
2. 위쪽 함수 목록에서 **setup**을 골라 **▶ 실행** → 구글 드라이브 권한 허용
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**
4. 웹 앱 주소를 열어 `사진첩 저장 가능 · 버전 4`가 보이면 완료

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 화면 (GitHub Pages로 공개) |
| `config.js` | 저장공간 주소를 넣는 곳 |
| `apps-script/Code.gs` | 저장공간 역할을 하는 구글 Apps Script |

따로 서버를 빌리지 않아요. 메시지는 **선생님 구글 드라이브의 구글 시트**에 저장되고, 화면은 **GitHub Pages**가 무료로 보여 줘요.

## 설치 방법 (처음 한 번)

### 1단계. 구글 시트 만들기
1. [Google Sheets](https://sheets.google.com)에서 빈 스프레드시트를 만들고 이름을 `롤링페이퍼 저장소`로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장해요.

### 2단계. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 골라요.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정하고 배포해요.
4. 권한 확인 창이 뜨면 본인 계정으로 허용해요. ("확인되지 않은 앱" 화면이 나오면 **고급 → 이동**)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.

> 학교 Google Workspace 계정은 관리자 설정 때문에 "모든 사용자" 옵션이 없을 수 있어요. 그럴 땐 개인 Gmail 계정으로 시트를 만들어 주세요.

### 3단계. 주소 연결하기
`config.js`를 열어 `API_URL` 따옴표 안에 복사한 주소를 붙여 넣고 저장(커밋)해요.

### 4단계. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `/(root)`** 를 선택하고 Save.
잠시 뒤 `https://gus-wn.github.io/cake_rolling_paper/` 에서 사이트가 열려요.

## 사용 방법

1. 첫 화면에서 받는 사람, 한마디, 케이크 맛을 고르고 **케이크 굽기**
2. **링크 복사**로 친구들에게 공유 (링크 끝 `#cake-코드`가 케이크 주소예요)
3. 메시지가 모이면 **🖨 B4로 출력하기** (인쇄 창에서 용지를 B4로 골라 주세요)

## 관리

- 메시지는 쓴 사람(같은 기기·브라우저)과 케이크를 만든 사람이 지울 수 있어요.
- 선생님은 구글 시트에서 행을 직접 지우거나 고칠 수 있어요. (`cakes` 탭, `toppings` 탭)
- 케이크 하나에 토핑은 최대 200개예요.
- 다른 사람에게 링크가 퍼지면 누구나 메시지를 쓸 수 있으니, 수업용으로는 링크를 학급 안에서만 공유해 주세요.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요. 주소는 그대로예요.
